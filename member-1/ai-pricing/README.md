# QYVRENZA AI Subscription & Pricing

## Introduction
A standalone pricing interface for users comparing QYVRENZA plans for personal and team use.

## What the UI pattern is
A pricing page presents plan boundaries, costs, and key differences so visitors can make an informed choice.

## Common use cases
- AI and SaaS subscription plan selection
- Explaining individual, team, and organization tiers
- Answering billing and feature questions before signup

## Relevance to modern web development
Transparent plan details and a usable comparison help people understand recurring costs and limits before they begin a subscription flow.

## Design patterns researched
Three-tier pricing, a monthly/yearly segmented control, a highlighted middle plan, a comparison table, progressive FAQ disclosures, and responsive overflow handling.

## What our implementation adds
Original QYVRENZA pricing visuals, an updating billing toggle, explicit annual total disclosure, selectable plan states, a detailed comparison table, and native keyboard-accessible FAQ accordions.

## Technologies used
HTML5, CSS3, and vanilla JavaScript. Google Fonts are optional; system sans-serif fallbacks are provided. No backend or paid API is required.

## Features
- Explorer, Studio, and Company plans with distinct, stated inclusions
- Monthly and yearly display for Studio; annual billing total is shown explicitly
- Plan selection feedback and five expandable FAQs

## Instructions to run
Open `index.html` directly in a browser, or open this folder in VS Code and use the Live Server extension's **Open with Live Server** command.
