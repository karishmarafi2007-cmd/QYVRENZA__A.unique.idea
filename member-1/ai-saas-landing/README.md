# QYVRENZA AI SaaS Landing Page

## Introduction
An original, responsive launch page for QYVRENZA: The Interface Intelligence Collection.

## What the UI pattern is
A product landing page introduces a product, explains its value, and gives visitors a clear next step.

## Common use cases
- Launching an AI or SaaS product
- Presenting a curated product or template collection
- Explaining a product's capabilities and team

## Relevance to modern web development
AI products can be technically complex. A clear narrative, accessible navigation, and responsive content help visitors understand the product before they engage with it.

## Design patterns researched
Editorial hero composition, a responsive navigation menu, repeated feature and template grids, progressive section hierarchy, and an animated abstract signal visualization.

## What our implementation adds
QYVRENZA's original visual identity, an animated network-inspired hero, a working dark/light theme switch, mobile navigation, and accessible template preview dialogs.

## Technologies used
HTML5, CSS3, and vanilla JavaScript. Google Fonts are optional; system sans-serif fallbacks are provided. No backend or paid API is required.

## Features
- Responsive landing page with collection, capabilities, process, team, and footer sections
- Theme toggle, mobile menu, and three interactive preview dialogs
- Reduced-motion support and semantic landmarks

## Instructions to run
Open `index.html` directly in a browser, or open this folder in VS Code and use the Live Server extension's **Open with Live Server** command.
